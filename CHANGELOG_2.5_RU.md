# Game Audio Bridge 2.5 — точный формат и сопоставление каналов

- Удалён промежуточный путь Float32 → PCM Int32 → Float32. Float32 буферы передаются без изменения байтов; для типичной WASAPI 7.1 маски `0x63F` порядок каналов уже совпадает с OpenAL 7.1.
- Добавлено явное сопоставление WASAPI `WAVEFORMATEXTENSIBLE.dwChannelMask` с каноническим порядком каналов OpenAL MCFORMATS. Сэмплы при необходимости переставляются целиком, без изменения битности или числового значения. Для `0x63F` сопоставление identity и данные копируются напрямую.
- DownMix, ресемплинг, изменение битности и автоматическое усиление не выполняются. Частота дискретизации, число каналов и формат сэмплов сохраняются.
- Float64 передаётся без преобразования только для mono/stereo при наличии соответствующих enum `AL_EXT_double`. Для многоканального Float64 и signed PCM Int64 стандартный OpenAL не предоставляет универсального подходящего enum; GAB не переинтерпретирует эти данные и сохраняет исходный WASAPI путь.
- Добавлена проверка маски WASAPI и отказ от неоднозначной многоканальной раскладки вместо случайного назначения каналов.

## Статус проверки

Архив содержит исходный код. Выполнены статические проверки и проверка целостности ZIP; сборка MSVC/Windows и проверка на Creative Sound Blaster X-Fi Elite Pro не выполнялись.
